# 急性腦中風教學投影片

單一 `index.html` 已內嵌教科書流程圖，能離線獨立開啟。

## GitHub Pages

建立 GitHub Repository，將 `index.html` 上傳至根目錄，前往 Settings → Pages 選取 Deploy from a branch / main / root。

手機可用上下捲動或底部上一頁／下一頁；桌機可用左右方向鍵、Page Up/Down。

教材為教學用途，臨床治療應依院內及現行指引。

EVT 補充：2019 經典條件、DEFUSE 3/DAWN/MR CLEAN-LATE、ATTENTION/BAOCHE、2026 AHA/ASA 更新。總頁數 41。


最後一頁為 Take-home Messages：IVT 標準 4.5 小時、符合條件 EVT 最長 24 小時、Door-to-X 目標。

- 在 TIA 頁後補充 ABCD² score（0–7 分）及使用限制。


### 一般支持性治療（2026-11 更新）
新增一頁：有低氧時維持 SpO₂ >94%、發燒處理、持續高血糖目標 140–180 mg/dL、低血糖 <60 mg/dL 應立即矯正；避免不必要的含糖輸液；thiamine 僅於營養不良／酒精使用等風險病人考慮，不應延誤葡萄糖救治。

本版補充「顱內壓升高：3% NaCl 緊急給法」，區分腦壓危象與嚴重症狀性低血鈉，並說明周邊靜脈給藥與監測。

## 2025 台灣 IVT 檢核表

IVT 章節含 2025 台灣腦中風學會總表三的三張重排教學頁。請以官方 PDF 第 34–35 頁的總表三、總表四及院內規範為最終依據。


更新：新增 Aspirin 單藥／DAPT 劑量與 21 天療程、IVT 後使用時機，以及高壓氧非標準治療提醒。

SAH Nimodipine 劑型更正：口服／NG 60 mg q4h × 21 天為首選；台灣有 0.02% 專用 IV 輸注液，可依仿單經 CVC、non-PVC 輸注管與 pump 持續滴注，口服劑型不可 IV。
